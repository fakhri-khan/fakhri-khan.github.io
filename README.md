# Dr. Fakhri Alam Khan, Academic Portfolio

Static academic portfolio website for Dr. Fakhri Alam Khan.

## Local preview

Open `index.html` directly in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

## GitHub Pages

The site is designed to publish from the repository root on the default branch. Enable GitHub Pages in the repository settings and choose the root folder as the deployment source.
